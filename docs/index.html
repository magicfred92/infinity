Pour ajouter/retirer des sites ou lancer un scraping depuis cette page, il faut un token d'accès personnel GitHub (fine-grained) limité à ce dépôt, avec les permissions Contents: Read and write et Actions: Read and write.

Ce token n'est stocké que dans ce navigateur (localStorage) et n'est envoyé qu'à api.github.com — jamais ailleurs.
